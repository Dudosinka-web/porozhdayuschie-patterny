# Порождающие паттерны — Builder и Factory

Лабораторная работа №1 по теме порождающих паттернов проектирования.

Проект выполнен на PHP в Yii 2.

## Реализовано

### 1. Строитель (Builder)
Создание объекта `User` тремя способами:
- из данных базы данных — `DbUserBuilder`;
- из данных формы — `FormUserBuilder`;
- из данных авторизации через VK — `VkUserBuilder`.

### 2. Фабрика
Создание постов для двух социальных сетей:
- `VkPost`;
- `TelegramPost`.

Для выбора конкретного типа используется `SocialPostFactory`.

## Проверка
Демонстрация выполнена в Yii по маршруту:

`/index.php?r=pattern/index`

## Структура

- `builders/` — строители пользователей;
- `models/` — модель `User`;
- `posts/` — фабрика и типы постов;
- `controllers/` — контроллер демонстрации;
- `views/` — представление;
- `docs/uml.puml` — исходник UML-диаграммы;
- `docs/uml.png` — UML-диаграмма.
