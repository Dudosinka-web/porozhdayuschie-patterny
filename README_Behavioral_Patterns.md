# Лабораторная работа: поведенческие шаблоны

В проект добавлены два паттерна:

1. **Наблюдатель (Observer)** — публикация новости вызывает уведомление всех подписчиков. Адреса находятся в таблице `news_subscribers`; `NewsPublisher` уведомляет подписчиков через `NewsObserverInterface`, а `EmailNewsSubscriber` формирует письма через Yii Mailer. В стандартной конфигурации Yii2 письма записываются в `runtime/mail`, а не отправляются по сети.
2. **Цепочка обязанностей (Chain of Responsibility)** — оформление заказа проходит последовательные обработчики: проверка склада → проверка авторизации → поиск адреса доставки в базе → создание заказа. При ошибке цепочка останавливается и возвращает сообщение соответствующего этапа.

## Установка

Скопируйте каталоги `patterns/`, `controllers/`, `views/`, `migrations/` в корень существующего Yii2 Basic-проекта, сохранив структуру. Если в целевом проекте уже есть одноимённый контроллер, объедините действия вместо перезаписи файла.

Из корня приложения выполните:

```bash
php yii migrate
```

Откройте:

```text
/index.php?r=behavior/index
```

На странице можно подписать email и опубликовать новость для всех подписчиков из БД. В блоке заказа нужно войти в приложение и сохранить адрес доставки, затем выбрать товар и количество. Миграция создаёт таблицы подписчиков, товаров на складе, адресов доставки и заказов, а также добавляет демонстрационные товары.

Graphviz-код UML находится в каталоге `uml/`.
